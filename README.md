# 손다음 (Sondaeum)

> "말 한마디면, 보고서는 AI가 작성해줍니다"

요양보호사가 하루 3~4가정을 방문할 때마다 어르신 상태를 기록해서 가족(보호자)에게
전달하는 일이 번거롭다는 문제를 해결하는 케어 리포트 서비스입니다. 요양보호사가
방문 중 말로 상황을 남기면, AI가 이를 정리해서 보호자에게 보기 쉬운 보고서로
전달합니다.

## 핵심 기능

1. **방문 기록** — 방문 시작/종료를 버튼으로 기록하고, 방문 중 상황을 음성 또는
   텍스트로 자유롭게 남깁니다.
2. **AI 요약 및 공유** — 남긴 내용을 AI가 **식사 / 복약 / 특이사항** 3항목으로
   자동 정리하고, 요양보호사가 검토·수정한 뒤 보호자에게 링크로 전송합니다.
   보호자가 언제 읽었는지도 자동으로 기록됩니다.
3. **누락 항목 자동 점검** — 식사·복약·특이사항 중 언급이 없거나 애매한 항목이
   있으면 AI가 표시해줘서, 보내기 전에 한 번 더 확인할 수 있습니다. (보호자에게
   보이는 문구에는 절대 섞이지 않습니다.)
4. **방문대상자 카드** — 어르신 프로필(나이·성별·알레르기·병력·복용약)과, 요양보호사가
   직접 남기는 지속 메모("특이사항")를 한 곳에서 확인·수정할 수 있습니다.
5. **방문 일정 캘린더** — 어르신별 돌봄 계약시간(요일/시간)을 등록하면, 홈 화면에서
   선택한 날짜에 방문 예정인 어르신만 자동으로 필터링됩니다.

## 왜 이렇게 만들었나

- **비콘 자동 연동 없이 수동 버튼으로 방문 시작/종료** — 정부 시스템 연동 허용
  여부가 불확실해서 이번 버전에서는 배제했습니다.
- **로그인 없이 시드 데이터로 동작** — 요양보호사 1명, 어르신 여러 명을 미리
  등록해두고 바로 체험할 수 있게 했습니다.
- **개인정보는 암호화 + AI 필터링 이중으로 보호** — 방문 전사문과 보고서 내용은
  DB에 평문으로 저장되지 않으며(AES-256-GCM), 저장 직전 AI가 주민번호·전화번호·
  주소·제3자 실명 등을 자동으로 걸러냅니다. 건강/돌봄 정보는 그대로 보존됩니다.

## 기술 스택

| 영역 | 기술 |
|---|---|
| 프레임워크 | Next.js 16 (App Router, TypeScript) |
| 데이터베이스 | Prisma 7 + Turso(libSQL) |
| 스타일 | Tailwind CSS v4 |
| AI 요약 | Groq (`openai/gpt-oss-120b`, 구조화 출력) |
| 음성 인식 | 브라우저 Web Speech API (Chrome/Edge, 미지원 브라우저는 텍스트 입력으로 대체) |
| 보안 | AES-256-GCM 필드 암호화 + AI 기반 개인정보 필터링 |
| 배포 | Vercel |

## 시작하기

```bash
npm install
npm run dev
```

브라우저에서 [http://localhost:3000](http://localhost:3000)을 엽니다.

같은 와이파이의 휴대폰에서 마이크 기능(녹음)까지 테스트하려면 HTTPS가 필요합니다:

```bash
npx next dev --experimental-https \
  --experimental-https-key ./certificates/localhost-key.pem \
  --experimental-https-cert ./certificates/localhost.pem
```

### 주요 명령어

| 명령어 | 설명 |
|---|---|
| `npx prisma migrate dev --name <이름>` | DB 스키마 변경 |
| `npx prisma db seed` | 시드 데이터 재생성 |
| `npx prisma studio` | DB 내용 확인 |
| `npx tsc --noEmit` | 타입 체크 |
| `npx eslint .` | 린트 |

`.env.local`에 `GROQ_API_KEY`가 설정되어 있어야 AI 요약 기능이 동작합니다.

## 화면 흐름

```
홈(어르신 목록) → 방문 시작 → 기록(음성/텍스트) → 방문 종료
  → AI 처리중 → 검토/수정 → 보호자에게 전송 → 열람 확인
```

## 주요 파일 위치

| 파일 | 역할 |
|---|---|
| `prisma/schema.prisma` | 데이터 모델 (Caregiver, Client, Visit, Report) |
| `app/api/visits/[id]/summarize/route.ts` | AI 요약 호출 |
| `app/visit/[id]/record/RecordScreen.tsx` | 방문 기록 화면 (음성 인식) |
| `app/g/[token]/page.tsx` | 보호자용 공개 화면 |
| `lib/crypto.ts` | 필드 암호화/복호화 |
| `lib/pii.ts` | 저장 전 개인정보 필터링 |
| `lib/schedule.ts` | 방문 일정(요일) 매칭 로직 |

## 현재 상태

전체 흐름(기록 → AI 요약 → 검토 → 전송 → 열람 확인)이 실제 배포 환경에서 동작을
확인했습니다. 개인정보 암호화와 AI 필터링도 적용 및 검증 완료 상태입니다.

더 자세한 작업 이력과 다음 할 일은 `../sondaeum-handoff.md`를 참고하세요.
