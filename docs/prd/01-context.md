# 01. 배경과 문제

손다음은 요양보호사가 방문 중 **말로 남긴 기록을 AI가 정리해 보호자에게 바로 전달**하는 AI 요양노트 서비스다. 출처: 발표 자료 `손다음_260829.pdf` (CAMPUS AX-TON DCU 손다음 조, 2026-08-29).

- 한 줄 소개: 내 손안의 AI 요양보조도우미
- 목표(Goal): 요양보호 현장에서 지나쳤던 순간도 놓치지 않게 기록할 수 있도록 돕는다.
- 현재 단계: MVP 배포 완료(`sondaeum-app.vercel.app`), 해커톤 본선 진출. 본선 심사는 **프로토타입 완성도**를 중요하게 본다.

## 배경

| 지표 | 값 | 출처(발표 자료 인용) |
| --- | --- | --- |
| 노령화지수 1위 지역 | 대구 군위군 1358.5 (전국 평균 205.2) | 국가데이터처(2026) |
| 노령화지수 2위 지역 | 경북 의성군 1086.9 | 국가데이터처(2026) |
| 요양보호사 평균 연령 | 62.6세 (2025년 기준) | 보건복지부(2026) |
| 요양보호사 1인당 감당 인원 | 1.5~1.9명(2023) → 1.9~2.4명(2030) → 3.0~3.7명(2040) | KDI(2026) |

대구·경북은 초고령사회로 빠르게 들어가고 있다. 요양보호사가 나이 들고 1인당 맡는 인원은 늘어서, 업무 생산성 저하와 과도한 노동 부담이 핵심 문제다.

## 문제

1. **요양보호사에게 시간이 부족하다.** 신체수발과 가사지원만으로 주어진 시간이 다 소진되어, 기록할 여유가 없고 기록의 질이 떨어진다. (프레시안, 2026)
2. **쏟아지는 기록 부담 때문에 현장에서 지침을 지키기 어렵다.** 인터뷰 결과:
   - 현직 간호사: "요양사들은 나이가 있어 앱으로 근무일지를 쓰는 것에 부담을 가지고 있을 것 같아요. … 제한된 3시간 서비스 시간에 30분 이상을 기록에다가 쓰는 모습을 현장에서 많이 보았어요."
   - 현직 요양보호사: "기록은 즉시 하는 게 원칙이어서 제때 기록을 하려고 노력하지만 가끔 돌봄 업무가 너무 바쁘다 보면 기록하는 걸 잊어버리기도 해요."

## 유사 서비스와 포지션

두 축(텍스트 ↔ 음성·AI, 행정·청구 관리 ↔ 현장 돌봄·보호자 소통)으로 국내 서비스를 나눴다.

| 사분면 | 특징 | 해당 서비스 |
| --- | --- | --- |
| 제1사분면 (음성·AI + 현장 돌봄·보호자 소통) | 말로 기록하고 기록 즉시 보호자에게 공유 | **손다음** |
| 제2사분면 (텍스트 + 현장 돌봄·보호자 소통) | 텍스트 기록 기반 보호자 소통 | 케어로그 |
| 제3사분면 (텍스트 + 행정·청구 관리) | 기존 서비스 대부분. 형식적 기재와 기록 부담 | 이지케어, 스마트장기요양, 케어포 |
| 제4사분면 (음성·AI + 행정·청구 관리) | 음성 AI지만 요양 현장 특화 아님, 돌봄 맥락 없음 | 클로바노트 |

차별점: 기록이 필요할 때 **즉시** 기록하고 저장할 수 있다.
