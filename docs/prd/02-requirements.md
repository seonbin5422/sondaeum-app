# 02. 개선 요구사항

PRD를 쓰기 전에 **무엇을 고치고 무엇을 새로 만들지**를 이 문서에서 먼저 확정한다. 모든 작업은 여기 있는 ID로 부르고, 담당자는 표의 `담당` 칸에 이름을 적는다.

기준: 해커톤 본선 제출용 프로토타입 · 사용자는 요양보호사와 보호자 · 2026-10-03 정리

### DIF-4 제출용 보고서 상세

- **만드는 사람**: 요양보호사가 수급자 화면에서 기간(예: 최근 1개월)을 고른다. 보호자도 대화방·보고서 링크에서 같은 보고서를 내려받을 수 있다.
- **내용**: 수급자 기본정보, 기간 내 방문 일시 목록, 식사·복약·배뇨·배변·혈압 기록 표, 특이사항 모음, 기간 중 변화 요약
- **형식**: A4 인쇄용 화면 → 브라우저 인쇄 또는 PDF 저장. 문서 하단에 "요양보호사 관찰 기록이며 의료적 진단이 아닙니다" 문구와 작성자·작성일
- **제출**: 앱이 의료기관·보험사에 직접 보내지 않는다. 보호자(또는 수급자)가 내려받아 제출한다. (LAW-10)

### DIF-5 수급자별 대화방 상세

- 수급자 1명 = 대화방 1개. 참여자는 담당 요양보호사와 등록된 보호자.
- 방문 보고서를 보내면 대화방에 보고서 카드가 자동으로 올라간다. 보호자는 그 아래에서 질문할 수 있다.
- 보호자는 로그인 없이 수급자별 전용 링크(만료 기한 있음)로 들어온다.
- 프로토타입에서는 실시간 연결 없이 몇 초마다 새 메시지를 확인하는 방식(폴링)으로 만든다.
- 요양보호사 홈의 수급자 카드에 안 읽은 메시지 수를 표시한다.
