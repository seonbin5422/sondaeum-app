# 기능 정리 (세부 PRD 작성용)

2026-11-01 `feature/v1120` 코드 기준으로 **지금 구현된 기능**만 정리했다. 2차 멘토링(10/23) 피드백대로 **대상 사용자 → 큰 기능 → 세부 기능** 순서로 나눴고, 세부 PRD는 큰 기능 단위로 하나씩 만든다. 괄호 안은 화면 ID(C-xx 요양보호사, G-xx 보호자)와 요구사항·결정 ID.

범위: `/v1120` 화면과 서버 액션만 봤다. 예전 화면(`app/visit` 등)과 `app/api` API는 넣지 않았다.

---

## 1. 요양보호사

### 1-1. 로그인·처음 설정
- **로그인 (C-01)**: 카카오 로그인(SEC-4), 로그인 없이 체험 계정으로 들어가는 "먼저 둘러보기"(OPS-1)
- **처음 설정 (C-02)**: 이름·자격번호 입력
- **동의 (C-21, LAW-3)**: 개인정보·건강정보(민감)·보호자 제공·국외 이전을 따로 동의, 항목마다 "자세히 보기"
- **개인정보 처리방침 (LAW-12)**

### 1-2. 홈 · 오늘의 돌봄 (C-03)
- 오늘 요일에 방문할 수급자 목록 (한국 시간 기준)
- 기록 상태에 따라 버튼이 바뀜: 기록하기 → 이어서 기록하기 → 기록 확인하고 보내기 → 전송 완료
- 일정 달력: 날짜별 방문 건수, 날짜를 누르면 그날 일정
- 수급자 등록 바로가기

### 1-3. 수급자 관리
- **수급자 목록 (수급자 탭)**: 담당 수급자 목록, 삭제한 수급자 되살리기
- **수급자 등록 (C-07)**
  - 수급자 정보: 이름·장기요양인정번호·방문 요일(필수), 나이·성별·등급·전화번호
  - 건강 정보: 병력·복용 약·알레르기
  - 보호자: 관계(가족 / 사회복지사 / 주민센터 / 후견인 / 없음, D-49), 이름·전화번호
  - 방문 시작·끝 시간
- **수급자 정보 (C-05)**: 방문 전에 볼 "꼭 기억할 것"(병력·알레르기·복용 약), 보호자 연락처
- **정보 수정 (C-08)**
- **삭제 (C-10)·완전히 지우기 (C-11)**: 지우기 전에 기관 시스템으로 옮겼는지 확인(LAW-8)
- **방문 기록 (C-22, DIF-9)**: 날짜별 방문과 보고서, 서류 만들기로 가는 입구
- **보호자 게시판 초대 (C-23)**: 등록하면 바로 이 화면으로 옴, 카카오 공유 카드나 링크로 초대
- 보안: 수급자 이름·전화번호 암호화 (SEC-5)

### 1-4. 돌봄 기록
- **녹음·기록 (C-12)**
  - 입력 방법: 음성 인식, 글로 쓰기, 음성 파일 올리기(4MB까지)
  - 저장: 문장마다 바로 저장해서 앱이 꺼져도 내용이 남음 (D-27)
  - 안내: 기록지 순서대로 질문 목록을 보여 주고, 말하는 동안 찾은 값을 표시
  - 빠진 항목을 소리로 되묻기: "다 말했어요" 뒤 못 찾은 칸을 하나씩 묻고 말로 답함 (D-51, 검토 중)
  - 체험 계정 전용: 예시 내용 넣기
- **AI 정리 (C-13)**
  - 녹음 내용을 급여제공기록지 항목으로 정리 (D-24)
  - AI로 보내기 전에 개인정보 지우기 (LAW-6)
  - AI 사용 횟수 제한 (SEC-3), AI가 실패하면 낱말 찾기로 대신 채움
- **기록 확인 (C-14)**
  - 항목별 체크와 선택: 신체활동, 인지·정서, 가사, 변화상태, 배변 (DIF-6)
  - 빈 칸에 "확인 필요" 표시, 항목마다 "내가 한 말"(원문 근거) 보기
  - 특이사항: 기록지용 문장과 보호자용 문장, 조치가 빠졌으면 AI 질문과 "말로 더하기" (D-43)
  - 누구에게 알렸는지 고르기, "특이사항 없음" 버튼
  - 임시저장, 다시 들어오면 "빠진 내용 더 말하기" (D-42)
- **보낼 내용 보기 (C-15)**: 보호자 보고서 미리보기, 빠진 항목 확인창
- **보내기 (C-16)**: 카카오톡 공유, 링크 복사. 보호자가 없으면 "기록 저장"만 하고 보내지 않음. 보낸 뒤에는 고칠 수 없음 (STB-1)

### 1-5. 게시판 (DIF-5, D-15)
- 게시판 목록: 수급자별 게시판, 안 읽은 댓글 수
- 수급자 게시판 (C-18): 보낸 보고서와 올린 서류가 글로 올라옴
- 게시글 상세: 보고서 요약과 댓글 쓰기, 읽음 처리

### 1-6. 서류 만들기 (DIF-4, D-29)
- 서류 고르기 (C-19): 진료 참고용 요약 또는 급여제공기록지 선택, 기간은 하루·1주·1개월·직접 고르기
- 진료 참고용 요약 (C-20): PDF로 저장, 인쇄, 게시판에 올리기
- 급여제공기록지: 날짜마다 한 장, 손가락 서명칸과 서명 못 하는 사유 (D-48)

### 1-7. 내 정보
- 프로필 보기와 고치기 (C-06)
- 동의한 내용 보기 (동의 날짜 포함)
- 개인정보 처리방침, 로그아웃

## 2. 보호자 (로그인 없이 받은 링크로 들어옴)

### 2-1. 보고서 (G-01)
- 받은 보고서 열기: 보낸 기록만 보이고, 지운 수급자의 보고서는 안 보임
- 보고서 내용: 기록지 순서를 읽기 쉬운 말로, 지난 방문과 비교, 특이사항 (DIF-2)
- "게시판으로 이동하기" 버튼

### 2-2. 게시판 (G-02)
- 그 어르신의 보고서 글 전체 보기
- 게시글 상세에서 댓글 쓰기, 안 읽은 댓글 표시
- 요양보호사가 올린 진료 참고용 요약 보기와 PDF 저장

### 2-3. 보호자 앱 예시 (`/c/[token]`, D-44 P2)
아직 임시 데이터로 만든 예시다.
- 홈 (G-04): 어르신 정보는 보기만, 방문 일정, 보고서 모아보기
- 서류 만들기 (G-03): 요양보호사 화면과 같음
- 내 정보 (G-05)

---

## 3. 화면에는 안 보이는 공통 기능
- 개인정보 보호: 녹음 원문·기록·서명 암호화, 녹음 파일은 글로 바꾼 뒤 저장하지 않음
- AI 비용: 호출 횟수 제한, AI 실패 시 낱말 찾기로 대신 채움
- 마이크: 누를 때만 켜지고, 화면을 떠나면 꺼짐 (LAW-5)

---

## 4. 없는 기능 (멘토링 예시 중)
- 비밀번호 변경: 카카오 로그인이라 비밀번호가 없음
- 알림 설정: 알림 기능을 아직 만들지 않음
