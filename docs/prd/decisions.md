# 결정사항 기록

무엇을 왜 정했는지 적는다. 새 결정은 표 맨 위에 새 줄로 추가한다. 이미 있는 결정이 바뀌면 새 줄을 만들지 않고, 원래 줄의 결정·이유 칸에 `YYMMDD.ver: 바뀐 내용`을 날짜순으로 덧붙이고 상태를 "수정됨 (YYMMDD)"로 바꾼다. 처음 내용은 지우지 않는다.
