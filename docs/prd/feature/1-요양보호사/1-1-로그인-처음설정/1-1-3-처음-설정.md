# PRD: 처음 설정 (이름·자격번호)

| 대상 | 큰 기능 | 화면 | 경로 | 상태 |
| --- | --- | --- | --- | --- |
| 요양보호사 | 1-1 로그인·처음 설정 | C-02 | `/v1120/onboarding` (1/2단계) | 구현됨 · `feature/v1120` dcaa0df 기준 |

## 1. 배경

- 현재 문제: 보호자 보고서와 서류(급여제공기록지·진료 참고용 요약)에 작성한 요양보호사 이름이 들어가야 하는데, 카카오 닉네임은 실명이 아닐 수 있다.
- 왜 지금 필요한가: 동의 화면(C-21)을 붙이면서 처음 설정을 2단계(정보 → 동의)로 나눴다.
- 관련 문서/이슈: `docs/prd/07-features.md` 1-1, `docs/design/02-screens.md` C-02

## 2. 목표

- 사용자가 무엇을 할 수 있어야 하는가: 첫 로그인 때 이름과 자격번호를 한 번 적고 동의 단계로 넘어간다.
- 기대 효과: 보고서·서류의 작성자 정보가 실명으로 들어간다.

## 3. 대상 사용자

- 주요 사용자: 처음 로그인한 요양보호사
- 보조 사용자: 체험 계정 사용자 (둘러보기 뒤 이 화면으로 옴)
- 관리자 또는 운영자 영향: 없음

## 4. 범위

이번 작업에 포함:

- [x] "1 / 2" 단계 표시, "요양보호사님을 알려 주세요", "보호자 보고서에 이름이 들어가요."
- [x] 이름(필수), 요양보호사 자격번호(필수, 예시·"자격증에 적힌 번호예요." 안내)
- [x] 빈 칸이면 "다음" 버튼이 막히고 이유("이름을 적어 주세요"/"자격번호를 적어 주세요")를 보여 줌
- [x] 동의 전에는 서버에 저장하지 않고 이 탭(sessionStorage)에만 잠시 둠

이번 작업에 포함하지 않음:

- [ ] 자격번호 형식 검사·실제 자격 확인
- [ ] 소속 기관 입력
- [ ] 프로필 사진

## 5. 사용자 흐름

1. 요양보호사가 카카오 로그인(또는 둘러보기) 뒤 처음 설정 화면을 본다.
2. 이름과 자격번호를 적고 "다음"을 누른다.
3. 시스템은 두 값을 탭 저장소에 두고 동의 화면(C-21)으로 보낸다. 실제 저장은 동의를 마칠 때 한다 (1-1-4).

## 6. 기능 요구사항

- FR-1: 이름이 비었거나 자격번호가 공백뿐이면 "다음"을 비활성화하고 `disabledReason`을 보여 준다.
- FR-2: "다음"을 누르면 `sessionStorage["v1120-onboarding"]`에 `{ name, licenseNumber }`(앞뒤 공백 제거)를 두고 `/v1120/onboarding/consent`로 간다.
- FR-3: 서버 저장은 동의 화면 제출(`POST /api/caregivers/onboard`) 때 한다.

## 7. 비기능 요구사항

- 성능: 서버 호출 없음 (클라이언트 화면)
- 접근성: 입력칸 높이 56px(`h-14`), 라벨·입력 글자 18px, 필수 표시는 라벨 글자로 "(필수)"
- 보안: 동의 전에는 개인정보를 서버에 보내지 않는다.
- 로깅/모니터링: 없음

## 8. 수용 기준

- [ ] Given 처음 설정 화면에서 이름만 적었을 때, When 다음 버튼을 보면, Then 버튼이 막혀 있고 "자격번호를 적어 주세요"가 보인다.
- [ ] Given 이름 "박현우"와 자격번호를 적었을 때, When 다음을 누르면, Then 동의 화면("2 / 2")으로 가고 DB의 이름은 아직 바뀌지 않는다.
- [ ] Given 동의까지 마친 뒤, When 내 정보 탭을 열면, Then "박현우 요양보호사"와 적은 자격번호가 보인다.

## 9. 검증 계획

- 단위 테스트: 없음
- 통합 테스트: 없음
- 수동 확인: 카카오 첫 로그인·둘러보기 각각, 아이폰 Safari(sessionStorage 유지) 확인

## 10. 리스크와 열린 질문

- 리스크: 값을 탭 저장소에만 두므로, 동의 화면에서 새 탭을 열거나 탭을 닫으면 값이 사라진다 (동의 화면이 1단계로 돌려보냄).
- 열린 질문:
  - 처음 설정을 마치지 않은 계정이 `/v1120` 홈 주소로 바로 들어오는 것을 막는 코드가 없다. 막을지 (카카오 콜백만 자격번호 유무로 나눔)
  - 자격번호 형식(예: `2019-서울-012345`)을 검사할지
  - 카카오 닉네임을 이름 칸에 미리 채워 줄지
