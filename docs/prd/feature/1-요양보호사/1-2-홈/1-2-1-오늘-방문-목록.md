# PRD: 오늘 방문할 수급자 목록

| 대상 | 큰 기능 | 화면 | 경로 | 상태 |
| --- | --- | --- | --- | --- |
| 요양보호사 | 1-2 홈 · 오늘의 돌봄 | C-03 | `/v1120` (하단 메뉴 "홈") | 구현됨 · `feature/v1120` dcaa0df 기준 |

## 1. 배경

- 현재 문제: 요양보호사는 하루 3~4가정을 방문한다. 앱을 열었을 때 오늘 갈 집과 각 집의 기록 상태를 바로 알아야 한다.
- 왜 지금 필요한가: 서버(Vercel)가 UTC라서 요일을 그대로 세면 한국 아침 9시 전에는 어제 요일로 계산되는 문제가 있었다.
- 관련 문서/이슈: `docs/prd/07-features.md` 1-2, DIF-1, `docs/prd/04-prd.md` 하루 사용 시나리오 1

## 2. 목표

- 사용자가 무엇을 할 수 있어야 하는가: 홈을 열면 오늘(한국 시간) 방문할 수급자와 건수를 본다.
- 기대 효과: 오늘 할 일을 찾는 시간을 없앤다.

## 3. 대상 사용자

- 주요 사용자: 요양보호사
- 보조 사용자: 체험 계정 사용자
- 관리자 또는 운영자 영향: 없음

## 4. 범위

이번 작업에 포함:

- [x] 인사말 "{이름} 요양보호사님," + "오늘 돌봄 N건이에요"
- [x] 오늘 요일(KST)이 방문 요일인 수급자 + 요일이 아니어도 오늘 기록을 시작한 수급자
- [x] 삭제한 수급자 제외, 완전히 지우기 예약된 수급자 제외
- [x] 카드: 이름, 상태 배지, 방문 요일·시간, 안 읽은 보호자 댓글 링크, "정보 수정" 버튼, 상태 버튼(1-2-2)

이번 작업에 포함하지 않음:

- [ ] 휴무·대체 방문 같은 일정 예외 (DIF-10, P2)
- [ ] 방문 시간순 정렬 (지금은 이름 가나다순)
- [ ] 오늘 방문이 없을 때 전용 안내 화면

## 5. 사용자 흐름

1. 요양보호사가 앱을 열거나 하단 메뉴 "홈"을 누른다.
2. 시스템은 내 수급자 목록과 오늘(KST 0시~24시) 만든 방문, 안 읽은 댓글 수를 읽어 오늘 카드 목록을 만든다.
3. 요양보호사는 카드를 보고 기록하기 등 다음 할 일을 누른다.

## 6. 기능 요구사항

- FR-1: `myClients()`는 내 수급자(`purgeAt` 없음)를 이름순으로 읽는다. 읽기 전에 `purgeExpiredClients()`를 부른다.
- FR-2: `kstWeekday()`로 한국 시간 요일을 구하고, `isActive`이면서 (방문 요일에 오늘이 있거나 오늘 방문 기록이 있는) 수급자만 카드로 만든다.
- FR-3: `myTodayVisits()`는 KST 오늘 범위에 만든 내 방문 중 수급자별 가장 최근 것을 쓴다.
- FR-4: 카드에 `myUnreadByClient()`의 안 읽은 보호자 댓글 수를 붙인다.
- FR-5: 헤더에 건수를 보여 주고, 오른쪽에 "일정 보기"(1-2-3)를 둔다.

## 7. 비기능 요구사항

- 성능: 서버 컴포넌트, 방문·안 읽은 수를 `Promise.all`로 함께 읽음
- 접근성: 카드 이름 18px, 버튼 높이 큰 버튼(`Button`), 상태는 글자 배지로 (색만으로 구분하지 않음) (DIF-1)
- 보안: 로그인한 요양보호사의 수급자만 (SEC-2). 비로그인이면 `/v1120/login`으로 이동(`requireCaregiver`)
- 로깅/모니터링: 없음

## 8. 수용 기준

- [ ] Given 월·수·금 방문 수급자가 있을 때, When 한국 시간 월요일 오전 7시(UTC 일요일)에 홈을 열면, Then 그 수급자 카드가 보인다.
- [ ] Given 화요일에 방문 요일이 아닌 수급자 기록을 시작했을 때, When 홈으로 돌아오면, Then 그 수급자 카드도 보인다.
- [ ] Given 삭제한 수급자가 오늘 방문 요일일 때, When 홈을 열면, Then 그 카드는 보이지 않는다.
- [ ] Given 다른 요양보호사 계정으로 로그인했을 때, When 홈을 열면, Then 내 수급자가 하나도 보이지 않는다.

## 9. 검증 계획

- 단위 테스트: 없음. `kstWeekday`·`kstTodayRange`의 UTC 경계(KST 0~9시)를 STB-7에 넣을 수 있다.
- 통합 테스트: 없음
- 수동 확인: 체험 계정으로 요일별 확인, 오전 9시 전 확인

## 10. 리스크와 열린 질문

- 리스크: 오늘 방문이 없는 수급자 카드들은 `visitId`가 빈 값이라 React 목록 key가 겹친다 (경고·렌더링 오류 가능).
- 열린 질문:
  - 카드 순서를 방문 시작 시간순으로 바꿀지 (지금은 이름순)
  - 오늘 돌봄이 0건일 때 안내 문구를 둘지 (지금은 "0건이에요"와 아래 등록 버튼만)
  - 방문 요일 일정이 비어 있는 수급자를 홈에 보일지 (옛 화면 `isVisibleOn`은 항상 보였지만 1120은 안 보임)
