# PRD: 일정 달력

| 대상 | 큰 기능 | 화면 | 경로 | 상태 |
| --- | --- | --- | --- | --- |
| 요양보호사 | 1-2 홈 · 오늘의 돌봄 | C-04 | `/v1120` 홈 "일정 보기" → 아래에서 올라오는 시트 | 구현됨 · `feature/v1120` dcaa0df 기준 |

## 1. 배경

- 현재 문제: 홈은 오늘만 보여 준다. 다음 주 일정이나 특정 날짜에 몇 집을 가는지 보려면 수급자를 하나씩 열어야 한다.
- 왜 지금 필요한가: 와이어(278:2)에서 홈의 보조 기능으로 정했다.
- 관련 문서/이슈: C-04, DIF-1, `docs/design/02-screens.md`

## 2. 목표

- 사용자가 무엇을 할 수 있어야 하는가: 달력에서 날짜별 돌봄 건수를 보고, 날짜를 눌러 그날 갈 수급자와 시간을 본다.
- 기대 효과: 주·월 단위 일정을 앱 안에서 확인한다.

## 3. 대상 사용자

- 주요 사용자: 요양보호사
- 보조 사용자: 없음
- 관리자 또는 운영자 영향: 없음

## 4. 범위

이번 작업에 포함:

- [x] 홈 오른쪽 위 "일정 보기" 버튼 → 시트(`role="dialog"`), "닫기"
- [x] 월 달력, "‹ 이전 달"·"다음 달 ›"
- [x] 날짜마다 그날 돌봄 수("N건"), 0건이면 빈칸
- [x] 날짜를 누르면 고른 날 강조, 아래에 "M월 D일 (요일) 돌봄 N건"과 수급자 이름·시간 목록
- [x] 처음 열면 오늘 날짜가 골라져 있음
- [x] 0건이면 "이 날은 예정된 돌봄이 없어요."

이번 작업에 포함하지 않음:

- [ ] 실제 방문 기록(보냄 여부) 표시 — 달력은 방문 요일 기준 예정만 보여 줌
- [ ] 일정 예외(휴무·대체 방문) (DIF-10)
- [ ] 달력에서 수급자 눌러 이동

## 5. 사용자 흐름

1. 요양보호사가 홈에서 "일정 보기"를 누른다.
2. 시스템은 이번 달 달력과 오늘 일정 목록을 보여 준다.
3. 요양보호사가 날짜를 누르거나 달을 넘긴다.
4. 시스템은 고른 날의 수급자·시간 목록을 보여 준다.

## 6. 기능 요구사항

- FR-1: 홈에서 받은 수급자 목록(`clients`) 중 `isActive`이고 `scheduleDays`에 그 날 요일이 있는 수급자를 그날 돌봄으로 센다.
- FR-2: 날짜 칸은 날짜 숫자와 건수를 두 줄로, 건수가 없어도 줄 높이를 비워 둔다.
- FR-3: 고른 날은 `aria-pressed`와 배경색으로 표시한다.
- FR-4: 목록의 시간은 `scheduleLabel`의 마지막 부분(예: `09:00–11:00`)이다.
- FR-5: 서버 호출 없이 클라이언트에서 계산한다.

## 7. 비기능 요구사항

- 성능: 추가 요청 없음
- 접근성: 날짜 칸 높이 60px, 버튼 높이 48px 이상, 날짜 18px, 시트는 `aria-modal`, 범례("고른 날", "그날 돌봄 수") 표시
- 보안: 홈이 이미 읽은 내 수급자만 쓴다.
- 로깅/모니터링: 없음

## 8. 수용 기준

- [ ] Given 월·수 방문 수급자 2명, 월 방문 수급자 1명이 있을 때, When 일정 달력을 열면, Then 월요일 칸에 "3건", 수요일 칸에 "2건"이 보인다.
- [ ] Given 달력에서, When 일요일(방문 없음)을 누르면, Then "돌봄 0건"과 "이 날은 예정된 돌봄이 없어요."가 보인다.
- [ ] Given 삭제한 수급자가 있을 때, When 그 수급자의 방문 요일을 누르면, Then 목록에 그 수급자가 없다.
- [ ] Given 달력에서, When "다음 달 ›"을 누르면, Then 다음 달 달력이 나오고 고른 날 목록은 그대로다.

## 9. 검증 계획

- 단위 테스트: 없음
- 통합 테스트: 없음
- 수동 확인: 체험 계정으로 월 넘기기, 아이폰 화면에서 시트 스크롤

## 10. 리스크와 열린 질문

- 리스크: 달력의 "오늘"과 요일 계산은 **휴대폰 시간대**(브라우저 `new Date()`)를 쓴다. 홈 목록(1-2-1)은 KST 기준이라 해외 시간대 기기에서는 둘이 다를 수 있다.
- 열린 질문:
  - 지난 날짜에 실제로 보낸 기록 여부(✓)를 달력에 표시할지
  - 오늘 날짜를 고른 날과 다르게 따로 표시할지 (지금은 고른 날 강조만 있음)
  - 달력에서 수급자를 누르면 수급자 정보나 기록으로 가게 할지
