# PRD: 수급자 등록 바로가기

| 대상 | 큰 기능 | 화면 | 경로 | 상태 |
| --- | --- | --- | --- | --- |
| 요양보호사 | 1-2 홈 · 오늘의 돌봄 | C-03 → C-07 | `/v1120` 빈 홈 버튼 → `/v1120/client/new` (+ 둘러보기 `/v1120/tour`) | 구현됨 · `feature/v1120` ae8748e 기준 |

## 1. 배경

- 현재 문제: 처음 가입한 요양보호사는 수급자가 없어 홈이 비어 있다. 수급자 탭으로 가야 등록할 수 있으면 첫 기록까지 단계가 늘어난다.
- 왜 지금 필요한가: 첫 사용자가 바로 수급자를 등록하고 기록까지 가도록 홈에 입구를 둔다.
- 관련 문서/이슈: `docs/prd/07-features.md` 1-2, C-07

## 2. 목표

- 사용자가 무엇을 할 수 있어야 하는가: 홈에서 바로 새 수급자 등록 화면으로 간다.
- 기대 효과: 첫 수급자 등록까지 화면 이동을 한 번으로 줄인다.

## 3. 대상 사용자

- 주요 사용자: 처음 쓰는 요양보호사, 새 수급자를 맡은 요양보호사
- 보조 사용자: 체험 계정 사용자
- 관리자 또는 운영자 영향: 없음

## 4. 범위

이번 작업에 포함:

- [x] 수급자가 없으면(처음 가입) 홈의 "오늘은 예정된 방문이 없어요." 카드 안에 "+ 수급자 등록하기" 버튼. 수급자가 있으면 홈에는 두지 않고 수급자 탭에서 등록한다
- [x] 누르면 `/v1120/client/new` (등록 화면은 1-3-2)
- [x] 수급자가 없는 홈을 처음 열면 "+ 수급자 등록하기"만 짚는 코치마크: "먼저 어르신을 등록하세요" (D-57 261114.ver)
- [x] 등록을 마치고 홈에 오면 한 번 "사용법을 둘러볼까요?"("나중에" / "둘러보기"). "둘러보기"는 `/v1120/tour`에서 체험 계정 예시 화면 캡처 9단계 위에 짚어 설명한다("건너뛰기"·"이전"·"다음"·"시작하기"). 이때 홈 코치마크는 둘러보기가 대신한다 (D-57 261114.ver)
- [x] 게시판 탭·서류 만들기도 수급자가 없으면 "+ 수급자 등록하기" 버튼을 보여 준다 (1-5-1, 1-6-1)

이번 작업에 포함하지 않음:

- [ ] 기관 시스템에서 수급자 가져오기

## 5. 사용자 흐름

1. 수급자가 없는 요양보호사가 홈을 열면 코치마크가 "+ 수급자 등록하기"를 짚는다. 요양보호사가 버튼을 누른다.
2. 시스템은 수급자 등록 화면을 연다.
3. 요양보호사는 등록을 마치고 보호자 초대 또는 수급자 정보 화면으로 간다 (1-3-2).
4. 홈으로 돌아오면 "사용법을 둘러볼까요?"가 한 번 뜬다. "둘러보기"를 누르면 둘러보기가 열린다.

## 6. 기능 요구사항

- FR-1: 오늘 방문이 없고 활동 중인 수급자가 0명일 때만 홈 빈 카드 안에 `LinkButton href="/v1120/client/new"`를 둔다(`data-coach="add-client"`).
- FR-2: 수급자 없는 홈은 `Coach id="home-empty"`와 `TourPending`(이 기기에 둘러보기 차례를 "pending"으로 표시)을 둔다. 수급자가 있는 홈은 `TourOffer`가 "pending"일 때만 제안하고, 열거나 "나중에"면 "done"으로 바꾼다.
- FR-3: 코치마크·둘러보기를 본 기록은 이 기기(localStorage)에만 남는다. 내 정보 "사용법 다시 보기"가 지운다 (1-7-1).

## 7. 비기능 요구사항

- 성능: 링크 이동만
- 접근성: 큰 버튼. 코치마크는 화면을 어둡게 덮고 짚은 곳만 밝게, 한 번에 설명 하나
- 보안: 등록 화면에서 로그인 확인 (`requireCaregiver`)
- 로깅/모니터링: 없음

## 8. 수용 기준

- [ ] Given 수급자가 0명인 요양보호사가, When 처음 홈을 열면, Then "오늘은 예정된 방문이 없어요." 카드 안 "+ 수급자 등록하기"를 짚는 코치마크가 보인다.
- [ ] Given 홈에서, When "+ 수급자 등록하기"를 누르면, Then 수급자 등록 화면이 열린다.
- [ ] Given 수급자가 한 명 이상인 요양보호사가, When 홈을 열면, Then 홈에는 "+ 수급자 등록하기"가 없다 (수급자 탭에 있음).
- [ ] Given 빈 홈을 본 기기에서 첫 수급자를 등록한 뒤, When 홈으로 오면, Then "사용법을 둘러볼까요?"가 한 번 뜨고 "둘러보기"를 누르면 "둘러보기 1 / 9 · 예시 화면"이 열린다.

## 9. 검증 계획

- 단위 테스트: 없음
- 통합 테스트: 없음
