# PRD: 빠진 항목 되묻기

| 대상 | 큰 기능 | 화면 | 경로 | 상태 |
| --- | --- | --- | --- | --- |
| 요양보호사 | 1-4 돌봄 기록 | C-12 (녹음 화면 안) | `/v1120/visit/[id]/record` | 구현됨 · 11/1 확정 (D-51) |

## 1. 배경

- 현재 문제: 녹음만 하고 바로 정리하면 빠진 칸이 많아 기록 확인(C-14)에서 손으로 채워야 했다. 특히 특이사항에 "기침하셨어요"처럼 관찰만 말하고 어떻게 도와드렸는지·누구에게 알렸는지는 빠지기 쉽다.
- 왜 지금 필요한가: 기록 확인의 조치 질문(notesAsk, D-43)과 "누구에게 알렸나요?"를 녹음 직후로 앞당기면 말로 한 번에 끝낼 수 있다. 11/15 멘토링 시연 흐름에 들어간다.
- 관련 문서/이슈: `docs/prd/07-features.md` 1-4, `decisions.md` D-51, D-43, LAW-5

## 2. 목표

- 사용자가 무엇을 할 수 있어야 하는가: "다 말했어요"를 누르면 못 찾은 칸을 하나씩 글과 소리로 듣고, 녹음 버튼으로 바로 답한다.
- 기대 효과: 기록 확인에서 "확인 필요" 칸과 조치 누락이 줄어든다.

## 3. 대상 사용자

- 주요 사용자: 요양보호사
- 보조 사용자: 체험 계정 사용자 ("예시 내용 넣기"로 답을 채울 수 있음)
- 관리자 또는 운영자 영향: 없음. 질문 소리는 미리 만든 파일이라 AI 호출이 없다.

## 4. 범위

이번 작업에 포함:

- [x] 6칸 중 못 찾은 칸을 기록지 순서로 하나씩 묻기 (몸 돌봄·집안일은 시간이 빠져도 물음)
- [x] 특이사항에 문제 낱말이 있는데 도움·전달 낱말이 없으면 "도와드린 것"·"알린 사람" 질문 추가, "말씀하신 내용" 함께 표시
- [x] 질문 글 표시 + 음성 파일 재생(`public/v1120/ask/1~8.mp3`), "🔊 다시 듣기", 재생 실패 안내
- [x] 녹음 버튼으로 답하기, 답은 녹음 내용 끝에 붙음
- [x] "다음 질문", "그만 묻고 정리하기", 마지막은 "다 답했어요: AI로 정리하기"

이번 작업에 포함하지 않음:

- [ ] 말한 내용에 맞춰 질문을 고르는 기능 (상황별 질문 20~30개 중 AI가 선택, 다음 후보)
- [ ] AI가 질문을 그때그때 만들기 (아이폰에서 실시간 음성 API가 필요해 비용·지연·처리위탁 추가)
- [ ] 정식 서비스용 유료 음성 (Edge 음성은 시연용)

## 5. 사용자 흐름

1. 요양보호사가 녹음 화면에서 "다 말했어요: AI로 정리하기"를 누른다.
2. 시스템은 빠진 칸을 계산한다. 없으면 바로 정리(1-4-3)로 가고, 있으면 첫 질문 카드("빠진 내용을 여쭤볼게요 (1/N) · 칸 이름")를 띄우고 질문 소리를 튼다.
3. 요양보호사가 "녹음"을 눌러 답하고 끝낸다. 답은 녹음 내용 끝에 붙는다.
4. "다음 질문"을 누르면 다음 질문으로, 마지막에서 "다 답했어요"나 중간에 "그만 묻고 정리하기"를 누르면 정리로 간다.

## 6. 기능 요구사항

- FR-1: 빠진 칸 = 6칸 안내 중 찾은 값이 없거나 "시간을 말해 주세요"가 들어 있는 칸. 기록지 순서(몸 돌봄 → 말벗·인지활동 → 집안일·외출 → 지난번과 달라진 점 → 대소변 → 특이사항)로 묻는다.
- FR-2: 칸마다 정해 둔 질문 문장과 음성 파일(1~6.mp3)을 쓴다.
- FR-3: 특이사항 글에 문제 낱말(아프·통증·넘어·열이·기침·어지러·토하 등)이 있으면, 녹음 글에서 그 낱말 뒤에 도움 낱말(도와·드렸·찜질·부축 등)이 없을 때 "그때 어떻게 도와드렸나요?…"(7.mp3), 전달 낱말(알렸·전화·연락·보고 등)이 없을 때 "이 일을 보호자나 기관에 알리셨나요?…"(8.mp3)를 추가한다.
- FR-4: 소리는 버튼을 누른 순간에 튼다(아이폰 제약). iOS 17+는 `audioSession`을 playback으로 바꿔 무음 스위치가 켜져도 소리가 나게 하고, 마이크를 쓸 때 원래대로 돌린다.
- FR-5: 재생에 실패하면 "소리를 틀지 못했어요 (오류명). 질문은 위 글로 봐 주세요."를 보여 준다.
- FR-6: 질문 중 녹음을 누르면 재생을 멈추고 녹음한다. 다음 질문으로 넘어가면 녹음을 끝낸다.
- FR-7: 화면을 떠나면 재생을 멈춘다.

## 7. 비기능 요구사항

- 성능: 질문 소리는 정적 mp3 파일이라 서버·AI 호출이 없다.
- 접근성: 질문 카드는 `aria-live="polite"`, 질문 글 20px 이상(`text-xl`), 소리가 안 나도 글로 답할 수 있다.
- 보안: 답하는 녹음도 누를 때만 켠다 (LAW-5).
- 로깅/모니터링: 없음

## 8. 수용 기준

- [ ] Given 몸 돌봄 활동만 말하고 시간은 말하지 않았을 때, When "다 말했어요"를 누르면, Then 첫 질문이 "몸 돌봄"이고 "몇 분 정도 하셨나요?"를 묻는다.
- [ ] Given "점심 드시다 기침 두 번 하셨어요"만 말했을 때, When "다 말했어요"를 누르면, Then 질문 목록 끝에 "도와드린 것"과 "알린 사람" 질문이 있고 카드에 "말씀하신 내용: …"이 보인다.
- [ ] Given "기침하셔서 등 두드려 드리고 따님께 전화했어요"라고 말했을 때, When "다 말했어요"를 누르면, Then 특이사항 조치 질문은 나오지 않는다.
- [ ] Given 6칸을 모두 말했을 때, When "다 말했어요"를 누르면, Then 질문 없이 정리 화면으로 간다.
- [ ] Given 질문 카드가 떠 있을 때, When "그만 묻고 정리하기"를 누르면, Then 남은 질문을 건너뛰고 정리 화면으로 간다.
- [ ] Given 아이폰 Safari에서, When 질문 카드가 뜨면, Then 질문 소리가 들린다 (11/1 실기기 확인).

## 9. 검증 계획

- 단위 테스트: 없음. 빠진 칸 판단은 `extractRecord` 기준이라 `_minutesSum.check.ts`가 시간 찾기를 일부 확인한다.
- 통합 테스트: 없음
- 수동 확인: 아이폰 Safari(무음 스위치 켬/끔)·안드로이드 크롬에서 질문 소리, 답 녹음, 정리까지 (OPS-2)

## 10. 리스크와 열린 질문

- 리스크:
  - 빠진 칸은 낱말 찾기 기준이라 AI라면 찾았을 칸도 물을 수 있다. 질문이 헛돌면 AI 정리 뒤에 묻도록 옮긴다 (코드 주석 shortcut).
  - 질문 문장을 바꾸면 mp3를 다시 만들어야 한다 (edge-tts).
  - Edge 음성은 공식 API가 아니라 본선 이후 서비스에는 쓸 수 없다.
- 열린 질문:
  - 몇 개 이상 빠지면 질문을 줄일지 (6칸 + 조치 2개 = 최대 8개를 다 묻는 게 사용성 테스트에서 괜찮은지, OPS-9)
  - 답하지 않고 "다음 질문"만 누른 칸을 기록 확인에서 따로 표시할지
  - 문제 낱말 목록(NOTE_PROBLEM)에 넣을 낱말을 누가 관리할지 (기획 vs 개발 1)
