# PRD: 급여제공기록지

| 대상 | 큰 기능 | 화면 | 경로 | 상태 |
| --- | --- | --- | --- | --- |
| 요양보호사 (보호자도 열람) | 1-6 서류 만들기 | 서류 · 급여제공기록지 결과 | `/v1120/client/[id]/documents/care-sheet?from&to` | 구현됨 · `feature/v1120` dcaa0df 기준 |

## 1. 배경

- 현재 문제: 요양보호사는 같은 기록을 기관 시스템(스마트장기요양)에 다시 입력한다. 서식 순서와 다르면 옮겨 적기 어렵고, 수급자·보호자 확인 서명도 종이로 받는다.
- 왜 지금 필요한가: 기록 항목을 장기요양급여 제공기록지(별지 제12호서식) 순서로 맞췄고(D-24, LAW-4), 서명칸을 기록지에서 받기로 했다(D-48, LAW-9).
- 관련 문서/이슈: DIF-4, LAW-4, LAW-9, D-24, D-29, D-48, `docs/prd/03-legal.md` 1절

## 2. 목표

- 사용자가 무엇을 할 수 있어야 하는가: 고른 기간의 보낸 방문을 날짜마다 한 장씩 기록지 서식으로 보고, 확인 서명을 받고, PDF 저장·인쇄한다.
- 기대 효과: 기관 시스템에 옮길 때 같은 순서로 보고 옮긴다. 공식 사본이 아니라는 점이 분명하다.

## 3. 대상 사용자

- 주요 사용자: 요양보호사
- 보조 사용자: 수급자·보호자 (서명), 보호자 (G-03에서 열람)
- 관리자 또는 운영자 영향: 기관은 이 문서를 공식 제출용으로 받지 않는다.

## 5. 사용자 흐름

1. 요양보호사가 서류·기간 고르기에서 "급여제공기록지"와 기간을 골라 "서류 만들기"를 누른다.
2. 시스템은 "급여제공기록지 · {기간} · N장"과 날짜별 기록지를 보여 준다.
3. 수급자나 보호자가 서명칸에 손가락으로 서명한다(못 하면 요양보호사가 사유를 적는다). 시스템은 한 획을 다 그릴 때마다 저장하고 "서명을 저장했어요"를 보여 준다.
4. 요양보호사가 "PDF로 저장"이나 "인쇄하기"를 누른다.

## 6. 기능 요구사항

- FR-1: 내 수급자가 아니면 404. 기간은 주소의 `from`·`to`, 없으면 오늘 하루.
- FR-2: 보낸 방문만 날짜순으로 한 장씩 그린다(`CareSheet`). 기록 확인의 "급여제공기록지" 탭도 같은 컴포넌트를 쓴다.
- FR-3: 요양보호사 화면에서는 `visitId`를 넘겨 서명을 저장하고, 보호자 화면에서는 넘기지 않는다.
- FR-4: `saveSignatures`는 내 방문이면 보낸 뒤에도 저장한다. 저장 전 `cleanSignatures`로 거른다: 칸 하나에 획 100개·점 4000개까지, 좌표는 칸(400×120) 안으로 붙이고 소수 한 자리로 줄임, 사유는 200자까지. 모양이 틀리면 "서명 모양이 올바르지 않아요."
- FR-5: 서명·사유가 모두 비면 저장 값을 지운다(null). 있으면 암호화해 `Report.signatures`에 둔다.
- FR-6: 사유는 글자마다가 아니라 입력이 멈췄을 때 저장한다. 저장 상태를 "서명 저장 중… / 서명을 저장했어요 / 서명을 저장하지 못했어요"로 보여 준다.
- FR-7: 서명 좌표는 칸 크기와 상관없이 0~400·0~120으로 모아, 화면을 돌리거나 인쇄해도 모양이 따라간다.

## 7. 비기능 요구사항

- 성능: 서명은 획 단위로 저장 (점마다 저장하지 않음).
- 접근성: 서명칸 `aria-label`("○○ 서명칸 (서명함)"), 서명할 수 없는 사람을 위한 사유 칸.
- 보안: 서명은 개인정보라 암호화 저장, 서버에서 값 모양을 다시 확인한다. 내 방문만 (SEC-2).
- 로깅/모니터링: 없음

## 8. 수용 기준

- [ ] Given 10/1~10/7에 보낸 방문이 3번일 때, When 급여제공기록지를 만들면, Then "3장"이 보이고 인쇄 미리보기에서 한 장씩 나뉜다.
- [ ] Given 배변을 말하지 않은 방문의 기록지를, When 열면, Then 대변·소변 실수 칸에 "확인 필요"가 보인다.
- [ ] Given 요양보호사 화면의 기록지에서, When 수급자가 서명칸에 한 획을 그으면, Then "서명을 저장했어요"가 보이고 새로고침해도 서명이 남아 있다.
- [ ] Given 보낸 방문의 기록지에서, When 서명하면, Then 저장된다 (보낸 뒤 잠금과 무관).
- [ ] Given 서명칸에 획 101개를 보내는 요청이, When 서버에 오면, Then "서명 모양이 올바르지 않아요."로 거부된다.
- [ ] Given 어떤 기록지든, When 아래를 보면, Then "공식 사본이 아니어서… 공식 용도로는 쓸 수 없어요" 고지가 있다.

## 10. 리스크와 열린 질문

- 리스크:
  - 같은 날 방문이 두 번이면 날짜를 키로 쓰는 화면에서 장이 겹칠 수 있다.
  - 서명이 화면에서 받은 선이라 법적 효력이 있는 전자서명은 아니다.
- 열린 질문:
  - 기록지에 요양보호사 이름 외에 기관명·수급자 장기요양인정번호 칸이 필요한지 (LAW-4 서식 항목과 대조 필요)
  - 보호자 화면(G-03)에서 서명을 받을지 (지금은 저장하지 않음)
  - 서명 불가 사유를 정해 둔 목록으로 고르게 할지, 지금처럼 글로 쓸지
  - DIF-3 기관 서류 초안(리뷰 중)과 이 기록지를 하나로 볼지, 따로 둘지
