# PRD: 내 정보 보기

| 대상 | 큰 기능 | 화면 | 경로 | 상태 |
| --- | --- | --- | --- | --- |
| 요양보호사 | 1-7 내 정보 | C-06 (내 정보 탭) | `/v1120/me` | 구현됨 · `feature/v1120` dcaa0df 기준 |

## 1. 배경

- 현재 문제: 요양보호사의 이름·자격번호는 보고서와 서류(급여제공기록지·진료 참고용 요약)의 작성자 칸에 들어간다. 처음 설정(C-02)에서 한 번 적고 나면 잘못 적었는지 확인할 곳이 없었다.
- 왜 지금 필요한가: 하단 메뉴를 홈·수급자·게시판·내 정보 4개로 정하면서(D-32) 프로필 모달(C-06) 대신 탭 화면으로 옮겼다. 동의 내용 보기·처리방침·로그아웃도 이 화면에서 들어간다.
- 관련 문서/이슈: `docs/prd/07-features.md` 1-7, `docs/design/02-screens.md` C-06, D-32

## 2. 목표

- 사용자가 무엇을 할 수 있어야 하는가: 로그인한 요양보호사가 자기 이름·자격번호를 확인하고, 고치기·동의 내용·처리방침·로그아웃으로 이동한다.
- 기대 효과: 서류에 잘못된 작성자 정보가 들어가는 일을 줄이고, 계정 관련 메뉴를 한곳에 모은다.

## 3. 대상 사용자

- 주요 사용자: 요양보호사 (카카오 로그인)
- 보조 사용자: 체험 계정("먼저 둘러보기") 사용자. 화면 아래에 "손다음 1120.ver 미리보기"가 추가로 보인다.
- 관리자 또는 운영자 영향: 없음

## 4. 범위

이번 작업에 포함:

- [x] 이름("○○ 요양보호사")과 자격번호 표시, 자격번호가 없으면 "미입력"
- [x] 메뉴: 내 정보 고치기 · 동의한 내용 보기 · 개인정보 처리방침 · 로그아웃
- [x] 체험 계정이면 "손다음 1120.ver 미리보기" 표시

이번 작업에 포함하지 않음:

- [ ] 비밀번호 변경 — 카카오 로그인이라 비밀번호가 없다
- [ ] 알림 설정 — 알림 기능(웹 푸시)을 해커톤 이후로 미뤘다 (11/1)
- [ ] 회원 탈퇴, 프로필 사진, 카카오 계정 정보(이메일 등) 표시

## 5. 사용자 흐름

1. 요양보호사가 하단 메뉴 "내 정보"를 누른다.
2. 시스템은 로그인 세션으로 요양보호사를 찾아 이름·자격번호와 메뉴 4개를 보여 준다.
3. 요양보호사는 내 정보를 확인하고, 필요하면 메뉴를 눌러 해당 화면으로 간다.

## 6. 기능 요구사항

- FR-1: `requireCaregiver()`로 로그인한 요양보호사의 `name`·`licenseNumber`·`isDemo`를 불러온다.
- FR-2: 이름은 "{이름} 요양보호사", 자격번호는 "자격번호 {번호}", 번호가 없으면 "미입력"으로 보여 준다.
- FR-3: 메뉴는 `/v1120/me/edit`, `/v1120/me/consent`, `/v1120/privacy` 링크와 로그아웃 버튼이다.
- FR-4: 로그아웃은 서버 액션 `logout()`으로 세션을 지우고 `/v1120/login`으로 보낸다.
- FR-5: `isDemo`가 참이면 화면 아래에 "손다음 1120.ver 미리보기"를 보여 준다.

## 7. 비기능 요구사항

- 성능: 서버 컴포넌트에서 요양보호사 1명만 읽는다. 추가 API 호출 없음.
- 접근성: 메뉴 한 줄 높이 64px 이상(`min-h-16`), 글자 크기 18px 이상(`text-lg`), "›" 기호는 `aria-hidden` (DIF-1)
- 보안: 로그인하지 않았으면 `requireCaregiver()`가 `/v1120/login`으로 보낸다. 다른 요양보호사 정보는 읽지 않는다 (SEC-1·2).
- 로깅/모니터링: 따로 없음

## 8. 수용 기준

- [ ] Given 처음 설정에서 이름 "이순자", 자격번호 "2024-001"을 저장한 요양보호사가, When 내 정보 탭을 열면, Then "이순자 요양보호사"와 "자격번호 2024-001"이 보인다.
- [ ] Given 자격번호가 비어 있는 계정이, When 내 정보 탭을 열면, Then "자격번호 미입력"이 보인다.
- [ ] Given 체험 계정으로 들어온 사용자가, When 내 정보 탭을 열면, Then 화면 아래에 "손다음 1120.ver 미리보기"가 보이고, 카카오 계정에서는 보이지 않는다.
- [ ] Given 내 정보 탭에서, When 로그아웃을 누르면, Then 로그인 화면으로 가고 `/v1120/me`에 다시 들어가도 내 정보가 보이지 않는다.

## 9. 검증 계획

- 단위 테스트: 없음 (표시만 하는 화면)
- 통합 테스트: 없음. STB-7 권한 테스트에 "로그인 없이 `/v1120/me` 접근 시 막힘"을 넣을 수 있다.
- 수동 확인: 카카오 계정·체험 계정 각각으로 위 수용 기준 4개, 아이폰 Safari·안드로이드 크롬 (OPS-2)

## 10. 리스크와 열린 질문

- 리스크: 체험 계정은 이름·자격번호가 예시 값이라 심사위원이 자기 정보로 오해할 수 있다.
- 열린 질문:
  - 회원 탈퇴를 어디에 둘지 (동의 철회·데이터 삭제와 함께 정해야 함)
  - 비밀번호 변경·알림 설정 메뉴가 멘토링 예시에 있었는데, 알림을 만들게 되면 이 화면에 넣을지
