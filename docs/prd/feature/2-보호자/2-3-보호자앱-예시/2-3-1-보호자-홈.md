# PRD: 보호자 홈 (예시)

| 대상 | 큰 기능 | 화면 | 경로 | 상태 |
| --- | --- | --- | --- | --- |
| 보호자 | 2-3 보호자 앱 예시 | G-04 | `/v1120/c/[token]` | **프로토타입 · 임시 데이터(`_mock.ts`)** · P2 (D-44, DIF-12) |

> 이 화면은 실제 DB와 연결되지 않은 예시다. 실제 보호자는 보고서 링크(2-1)와 게시판(2-2)을 쓴다.

## 1. 배경

- 현재 문제: 보호자는 보고서 링크 하나씩만 받아서 어르신 정보·방문 일정·지난 보고서를 한곳에서 보지 못한다.
- 왜 지금 필요한가: D-44(10/16)에서 보호자 앱(홈·게시판·내 정보)을 P2로 내리되, 모양을 보여 줄 예시는 만들어 두기로 했다.
- 관련 문서/이슈: `docs/design/02-screens.md` G-04, D-44, DIF-12

## 2. 목표

- 사용자가 무엇을 할 수 있어야 하는가: 보호자가 어르신 정보(보기만), 방문 일정, 보고서 모아보기, 서류 만들기를 한 화면에서 시작한다.
- 기대 효과: 본선 발표·멘토링에서 보호자 쪽 다음 단계를 보여 준다.

## 3. 대상 사용자

- 주요 사용자: 보호자 (예시)
- 보조 사용자: 심사위원·멘토 (시연)
- 관리자 또는 운영자 영향: 없음

## 4. 범위

이번 작업에 포함:

- [x] "안녕하세요, {보호자} 보호자님", 어르신 이름·나이·성별
- [x] 방문 일정 칩(`scheduleLabel`)과 "{요양보호사} 요양보호사가 방문해요"
- [x] "보고서 모아보기"(`/c/[token]/reports`), "서류 만들기"(2-3-2) 버튼
- [x] 어르신 정보(보기만): 장기요양등급·알레르기·병력·복용 중인 약, 없으면 "없음"
- [x] 하단 메뉴: 홈 · 게시판 · 내 정보
- [x] 처음 열 때 코치마크 3개: 방문 보고서 → 서류 만들기 → 아래 "게시판" (D-57). 보호자 내 정보(G-05)의 "사용법 다시 보기"는 홈으로 가서 처음부터 다시 보여 준다

이번 작업에 포함하지 않음:

- [ ] 실제 DB 연결, 보호자 로그인
- [ ] 어르신 정보 고치기 (고칠 내용은 게시판 댓글로 요양보호사에게 말함)

## 5. 사용자 흐름

1. 보호자가 예시 링크(`/v1120/c/{token}`)를 연다.
2. 시스템은 임시 데이터에서 토큰에 맞는 어르신을 찾아 홈을 보여 준다.
3. 보호자는 보고서 모아보기·서류 만들기·하단 메뉴로 이동한다.

## 6. 기능 요구사항

- FR-1: `chatTokenToClient[token]`으로 임시 수급자를 찾고, 없으면 404.
- FR-2: 어르신 정보 4칸은 값이 없으면 "없음"을 흐리게 표시한다.
- FR-3: 보고서 모아보기는 `ReportArchive`로 임시 이력을 날짜별로 보여 준다.

## 7. 비기능 요구사항

- 성능: 임시 데이터라 DB 요청 없음.
- 접근성: 본문 18px, 버튼 큰 터치 영역 (DIF-1)
- 보안: 실제 개인정보 없음 (임시 데이터).
- 로깅/모니터링: 없음

## 8. 수용 기준

- [ ] Given 임시 데이터에 있는 토큰으로, When 보호자 홈을 열면, Then 어르신 이름·방문 일정·어르신 정보 4칸이 보인다.
- [ ] Given 임시 데이터에 없는 토큰으로, When 홈을 열면, Then 404가 나온다.
- [ ] Given 보호자 홈에서, When "보고서 모아보기"를 누르면, Then 날짜별 보고서 목록이 열린다.

## 9. 검증 계획

- 단위 테스트: 없음
- 통합 테스트: 없음
- 수동 확인: 시연 전 점검(OPS-11)에서 예시 링크가 열리는지만 확인

## 10. 리스크와 열린 질문

- 리스크: 심사위원이 예시 화면을 실제 기능으로 오해할 수 있다.
- 열린 질문:
  - 예시 화면에 "예시 화면" 표시를 넣을지
  - 실제로 만든다면 보호자 로그인 방식(카카오 / 링크 + 인증번호)을 무엇으로 할지 (D-44)
  - 보호자 앱 게시판 예시(`/c/[token]/chat`)의 글을 누르면 실제 보고서 경로(`/g/[shareToken]`)로 가는데, 임시 토큰이라 예시 보고서가 보인다. 이 연결을 유지할지
