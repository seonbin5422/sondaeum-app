# PRD: 서류 만들기 (보호자 예시)

| 대상 | 큰 기능 | 화면 | 경로 | 상태 |
| --- | --- | --- | --- | --- |
| 보호자 | 2-3 보호자 앱 예시 | G-03 | `/v1120/c/[token]/documents` → `documents/summary` · `documents/care-sheet` · `documents/status-change` | **프로토타입 · 임시 데이터(`_mock.ts`)** · P2 (D-26, D-29, D-44, D-61) |

> 실제 DB와 연결되지 않은 예시다. 실제 보호자는 요양보호사가 게시판에 올린 요약(2-2-3)만 본다.

## 1. 배경

- 현재 문제: 보호자가 원하는 기간의 건강 기록 요약이 필요할 때마다 요양보호사에게 부탁해야 한다.
- 왜 지금 필요한가: D-26에서 보호자도 서류 종류·기간을 직접 고르게 하기로 했고, D-29에서 화면을 요양보호사 C-19와 같게 정했다. D-44로 P2가 되어 예시로만 만들었다.
- 관련 문서/이슈: `docs/prd/04-prd.md` 7절, DIF-4, LAW-10, D-26, D-29

## 2. 목표

- 사용자가 무엇을 할 수 있어야 하는가: 보호자가 서류 종류(건강 기록 요약/급여제공기록지/상태변화기록지)와 기간을 골라 A4 서류를 만들고 PDF로 저장한다.
- 기대 효과: 보호자 앱이 생기면 요양보호사를 거치지 않고 진료 자료를 만든다.

## 3. 대상 사용자

- 주요 사용자: 보호자 (예시)
- 보조 사용자: 심사위원·멘토 (시연)
- 관리자 또는 운영자 영향: 없음

## 4. 범위

이번 작업에 포함:

- [x] 안내: "요양보호사가 보낸 기록으로 만들어요", "진단서나 기관이 발급하는 공식 사본은 아니에요. 병원·기관에는 보호자님이 직접 내 주세요."
- [x] 요양보호사와 같은 `DocumentPicker`: 서류 종류 2가지, 기간(하루·최근 1주·최근 1개월·직접 고르기), 보낸 기록이 없는 기간은 막음
- [x] 건강 기록 요약 결과(`SummaryView`, `role="guardian"`), 급여제공기록지 결과, 상태변화기록지 결과(`StatusChangeView`, 기본 기간 10/1~예시 오늘, D-61)
- [x] PDF로 저장·인쇄하기

이번 작업에 포함하지 않음:

- [ ] 실제 DB 연결 (임시 이력 `historyOf`, 오늘 날짜도 고정값 `TODAY_ISO`)
- [ ] 게시판에 올리기 (요양보호사만)
- [ ] 외부 기관으로 직접 보내기 (D-14)

## 5. 사용자 흐름

1. 보호자가 보호자 홈에서 "서류 만들기"를 누른다.
2. 보호자가 서류 종류와 기간을 고르면, 시스템은 그 기간의 보낸 기록으로 서류를 만든다.
3. 보호자는 A4 화면을 보고 "PDF로 저장"으로 저장한다.

## 6. 기능 요구사항

- FR-1: 토큰으로 임시 수급자를 찾고, 없으면 404.
- FR-2: 고를 수 있는 날짜는 임시 이력 중 `status=SENT`인 날짜다.
- FR-3: 요약 화면은 `from`·`to`가 없으면 기본값 2026-09-09 ~ 2026-10-09를 쓴다.
- FR-4: 서류 내용·고지 문구는 요양보호사 서류(1-6)와 같다 (LAW-10).

## 7. 비기능 요구사항

- 성능: 임시 데이터, DB 요청 없음.
- 접근성: 요양보호사 C-19와 같음 (DIF-1)
- 보안: 실제 개인정보 없음.
- 로깅/모니터링: 없음

## 8. 수용 기준

- [ ] Given 보호자 예시 홈에서, When "서류 만들기" → 건강 기록 요약 → 최근 1개월을 고르면, Then 고지 문구가 있는 A4 요약 화면이 열린다.
- [ ] Given 보낸 기록이 없는 날짜를 "하루"로 고르면, When 만들기를 누르면, Then "이 기간에 보낸 기록이 없어요"로 막힌다.
- [ ] Given 보호자 요약 화면에서, When 버튼을 보면, Then "게시판에 올리기"는 없다.

## 9. 검증 계획

- 단위 테스트: `npx tsx app/v1120/_minutesSum.check.ts` (급여제공기록지 제공시간 합계, 요양보호사와 공용)
- 통합 테스트: 없음
- 수동 확인: 예시 링크에서 두 서류 모두 PDF 저장 확인

## 10. 리스크와 열린 질문

- 리스크: 임시 데이터와 고정 날짜를 써서 실제 날짜와 맞지 않아 보일 수 있다.
- 열린 질문:
  - 실제로 연결할 때 보호자가 볼 수 있는 기간을 제한할지 (예: 담당 요양보호사가 바뀌기 전 기록)
  - 급여제공기록지의 서명칸을 보호자 화면에서 보여 줄지, 서명할 수 있게 할지 (요양보호사 화면만 `visitId`를 넘김)
