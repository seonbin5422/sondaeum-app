# PRD: 마이크 제어 (누를 때만 녹음)

| 대상 | 큰 기능 | 화면 | 경로 | 상태 |
| --- | --- | --- | --- | --- |
| 공통 (요양보호사 녹음 화면) | 3 화면에 안 보이는 기능 | C-12 녹음·되묻기, C-14 말로 더하기 | `app/v1120/_components/useSpeech.ts` | 구현됨 · `feature/v1120` dcaa0df 기준 |

## 1. 배경

- 현재 문제: 수급자 집에서 마이크가 계속 켜져 있으면 수급자·가족의 사적인 대화까지 녹음될 수 있다 (개인정보보호법상 동의 없는 수집 위험).
- 왜 지금 필요한가: LAW-5(P0)로 "녹음은 누를 때만"을 정했고, 녹음 화면을 새로 만들면서(C-12, 되묻기 D-51) 회귀가 없는지 확인해야 했다.
- 관련 문서/이슈: LAW-5, `docs/prd/03-legal.md`, `_consent.ts`의 크롬 음성 인식 안내

## 2. 목표

- 사용자가 무엇을 할 수 있어야 하는가: 요양보호사가 녹음 버튼을 누른 동안만 마이크가 켜지고, 화면을 떠나면 자동으로 꺼진다.
- 기대 효과: 의도하지 않은 녹음이 생기지 않는다.

## 3. 대상 사용자

- 주요 사용자: 요양보호사
- 보조 사용자: 수급자·가족 (녹음될 수 있는 사람)
- 관리자 또는 운영자 영향: 없음

## 4. 범위

이번 작업에 포함:

- [x] 녹음 버튼(`start()`)을 눌러야 음성 인식 시작, 자동 시작 없음
- [x] 다른 앱으로 가거나 화면이 숨겨지면(`visibilitychange` → hidden) 끄고 다시 켜지 않는다
- [x] 화면을 떠나면(컴포넌트 해제) 끈다
- [x] 녹음 중 브라우저가 인식을 끝내면(`onend`) 사용자가 끄지 않았을 때만 이어서 새로 시작
- [x] 마이크 권한이 꺼져 있으면 "마이크 권한이 꺼져 있어요. 설정에서 마이크를 허용해 주세요."
- [x] 되묻기 답, "말로 더하기"도 같은 훅(`useSpeech`)을 쓴다

이번 작업에 포함하지 않음:

- [ ] 녹음 중 화면 밖 표시(알림 바 등) — 브라우저 기본 표시만
- [ ] 크롬 외 브라우저 음성 인식 (지원 안 되면 글로 쓰기)

## 5. 사용자 흐름

1. 요양보호사가 녹음 버튼을 누른다.
2. 시스템은 브라우저 음성 인식을 켜고, 다시 누르거나 화면을 떠나거나 앱을 바꾸면 끈다.
3. 요양보호사가 돌아와도 마이크는 꺼진 채이고, 다시 누를 때만 켜진다.

## 6. 기능 요구사항

- FR-1: `start()`만 인식을 시작한다. 시작 시 `keepRef=true`.
- FR-2: `stop()`은 `keepRef=false` 후 인식을 멈춘다.
- FR-3: `visibilitychange`에서 hidden이면, 그리고 화면 해제 시 `off()` — `keepRef=false`, `abort()`, 녹음 상태 false.
- FR-4: `onend`에서 `keepRef`가 참일 때만 새 인식을 만들어 이어 간다 (긴 녹음 끊김 방지).
- FR-5: `no-speech` 오류는 무시, `not-allowed`·`service-not-allowed`는 권한 안내, 그 외는 "음성 인식에 문제가 생겼어요. 다시 눌러 주세요."
- FR-6: 브라우저가 음성 인식을 지원하지 않으면 `supported=false`로 알려 화면이 글로 쓰기를 안내한다.

## 7. 비기능 요구사항

- 성능: 브라우저 내장 인식, 서버 요청 없음 (문장 저장은 별도, 1-4-1).
- 접근성: 녹음 상태를 화면에 표시(`recording`), 권한 오류는 글로 안내
- 보안: 크롬 음성 인식은 소리를 Google로 보낼 수 있어 동의 화면에 따로 알린다(`SPEECH_NOTICE`).
- 로깅/모니터링: 없음

## 8. 수용 기준

- [ ] Given 녹음 화면을 연 요양보호사가, When 아무 버튼도 누르지 않으면, Then 브라우저 마이크 표시가 켜지지 않는다.
- [ ] Given 녹음 중인 요양보호사가, When 홈 버튼으로 다른 앱에 갔다 돌아오면, Then 녹음이 꺼져 있고 다시 눌러야 켜진다.
- [ ] Given 녹음 중인 요양보호사가, When 뒤로 가기로 화면을 떠나면, Then 마이크 표시가 꺼진다.
- [ ] Given 마이크 권한을 거부한 브라우저에서, When 녹음 버튼을 누르면, Then "마이크 권한이 꺼져 있어요…" 안내가 보인다.

## 9. 검증 계획

- 단위 테스트: 없음 (브라우저 API 의존)
- 통합 테스트: 없음
- 수동 확인: 아이폰 Safari·안드로이드 크롬 실기기에서 위 수용 기준 4개 (OPS-2), 되묻기·말로 더하기에서도 반복

## 10. 리스크와 열린 질문

- 리스크: 브라우저마다 `onend`가 생기는 시점이 달라 긴 녹음 중 잠깐 끊길 수 있다.
- 열린 질문:
  - 아이폰 Safari에서 음성 인식 지원·`visibilitychange` 동작이 크롬과 같은지 (실기기 확인 기록이 되묻기 소리 재생만 있음)
  - 오래 켜 둔 녹음(예: 10분 이상)에 자동으로 끄는 시간 제한이 필요한지
